💻 Tech Stack - Hardware + Software + Architecture

🔧 Hardware Layer

ESP32: WiFi/BT, GPIO sensors, Edge capture
Raspberry Pi 4: On-device processing, Camera interface, Sensor hub
Sensors: MAX30102 HR/SpO2, DS18B20 Temp, GSR, Moisture, pH, TGAM1 EEG, MPX5010 Resp, Thermal sensor, IMU, Mic, MRI input
Camera: USB HD webcam for factory/school/disabled monitoring

🐍 Python Flask Backend

RESTful API, Data Ingestion, Real-time Pipeline, Auth & Routing, Firebase RTDB Asia-Southeast1, Vercel deployment
Code: app.py handles 12 routes, video streaming via multipart/x-mixed-replace

👁️ CV YOLOv8 + Mediapipe

YOLOv8n: Object detection - Helmet, Gloves, Shoes, Mobile, Person, Hammer, Book
Mediapipe: Pose 33 points dotted, Face Mesh 468 points dotted, Hands 21 points dotted
DeepFace: Emotion (7 emotions), Age, Gender, Race
Build Detection: Custom classifier - Slim/Medium/Built based on shoulder/waist ratio

🎙️ Whisper AI + Speech

Whisper base: Speech-to-Text, Voice Transcription, Multilingual ASR, Whisper analysis for unclear disabled voice
SpeechRecognition: Command mode detection "Command Mode"
Pipeline: Whisper → LLM RAG → Intent clarification

🧠 LLM + RAG + Generative AI

LLM: Flan-T5 base for intent understanding
RAG: Retrieval-Augmented Generation for contextual reasoning from knowledge base
Generative AI: Image generation for reports, Synthetic data for training, Anomaly generation
Use: Whisper unclear → Clear intent, Sign gesture → Sentence

🔊 TTS + Voice Clone

gTTS + Googletrans: Text-to-Speech in Hindi, Tamil, Telugu, Bhojpuri, English, Spanish, French, German, Japanese, Arabic
Coqui TTS XTTS-v2: Voice Cloning - Records his voice sample → Clones tone → Speaks for him in his own voice
Natural Female Voice: Welcome voice on homepage

📊 Frontend - Glass + Modes

Glass Buttons: backdrop-filter blur 20px, glass morphism top nav
Dark/Light: CSS variables toggle
Translation: 10 languages
Scroll: Up/Down fixed buttons, Arrow navigation between pages
Canvas: Hospital monitor ECG/PPG/Resp waveforms 60fps
